Featured · LLM + Semantic Search

InternPact

AI Recommender

An AI internship recommender. Upload a CV and an LLM turns it into a structured profile, then the app ranks live internship offers against that profile and shows exactly which skills you're missing and how to learn them.

  • LLM CV parsing (Claude, with Gemini and rule-based fallbacks) of PDF, DOCX or text CVs into skills, education and experience
  • Semantic matching with sentence-transformer embeddings and a FAISS index, combined with skill overlap in a hybrid match score
  • Live internship offers pulled from the JSearch API, plus a skill-gap analysis and a personalised learning path

Python, FastAPI, Claude API, sentence-transformers, FAISS, spaCy, React, Vite

Featured · Machine Learning

Heart Disease Prediction

ML App

An end-to-end machine learning app that predicts heart disease risk from clinical data. A scikit-learn model is trained on patient records and served through a Flask API, and each prediction comes with a confidence score.

  • Risk prediction for an individual patient, with model confidence
  • Interactive analytics dashboard for exploring the dataset
  • Cardiology research library and a nearby-hospital finder

Educational project, not medical advice.

Python, Flask, scikit-learn, JavaScript, Chart.js, Leaflet
